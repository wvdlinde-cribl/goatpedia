# Hand-added vendor logos

Put an SVG here as `<slug>.svg` when a vendor is not in [Simple Icons](https://simpleicons.org) or its icon there is not right. Then map the vendor to that slug in [`logos.yaml`](../logos.yaml). A file here wins over Simple Icons.

Use the vendor's official logo or icon from its press or brand page. Keep the file small and square: a single-colour path in a `0 0 24 24` viewBox works best.
